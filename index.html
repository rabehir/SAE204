Mode d'emploi - Utilisation de SweetAlert2

SweetAlert2 est une bibliothèque JavaScript qui permet de créer des popups élégants et interactifs, en remplacement des boîtes de dialogue natives de JavaScript, comme alert() ou confirm().

Il offre des alertes personnalisables avec des animations, des boutons, des champs de saisie, et plus encore.

1. Installation

Il existe plusieurs façons d'utiliser SweetAlert2 :

  • Via CDN : ajoutez simplement les liens vers le fichier CSS et le script JavaScript dans votre HTML :
    • <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/sweetalert2@11/dist/sweetalert2.min.css">
<script src="https://cdn.jsdelivr.net/npm/sweetalert2@11/dist/sweetalert2.min.js"></script>
  • En local : Téléchargez les fichiers sweetalert2.min.js et sweetalert2.min.css, puis liez-les dans votre projet.

2. Affichage de base

Pour afficher une alerte simple, utilisez la fonction Swal.fire() :

Swal.fire('Titre', 'Message de l\'alerte');

Cela affichera une boîte de dialogue avec un bouton pour la fermer.

3. Personnalisation des alertes

SweetAlert2 vous permet de personnaliser les alertes avec des options supplémentaires :

  • Type d'alerte : Définissez un type d'alerte, tel que success, error, warning, etc.
    • Swal.fire({
    icon: 'success',
    title: 'Succès !',
    text: 'L\'opération a réussi !'
});
  • Afficher une saisie utilisateur : Ajoutez un champ de saisie pour que l'utilisateur puisse entrer des informations :
    • Swal.fire({
    title: 'Quel est votre prénom ?',
    input: 'text',
    inputPlaceholder: 'Entrez votre prénom'
});
  • Confirmation d'action : Utilisez une boîte de dialogue avec des boutons de confirmation et d'annulation :
    • Swal.fire({
    title: 'Êtes-vous sûr ?',
    text: 'Cette action est irréversible.',
    icon: 'warning',
    showCancelButton: true,
    confirmButtonText: 'Oui',
    cancelButtonText: 'Non'
});

4. Fonctions avancées

SweetAlert2 propose également des fonctionnalités avancées :

  • Toast notifications : Notifications discrètes dans le coin de l'écran, idéales pour informer l'utilisateur sans interrompre son expérience :
    • Swal.mixin({
    toast: true,
    position: 'top-end',
    showConfirmButton: false,
    timer: 3000,
    timerProgressBar: true
}).fire({
    icon: 'info',
    title: 'Opération réussie !'
});
  • Étapes multiples : Utilisez des alertes consécutives pour guider l'utilisateur à travers plusieurs étapes, comme un assistant :
    • Swal.queue([
    {
        title: 'Étape 1',
        text: 'Introduction à l\'étape 1'
    },
    {
        title: 'Étape 2',
        text: 'Passons à l\'étape 2'
    }
]);
  • Formulaire personnalisé : Créez des formulaires interactifs pour collecter des informations avec plusieurs champs :
    • Swal.fire({
    title: 'Inscription',
    html: '<input id="name" class="swal2-input" placeholder="Votre Nom"><input id="email" class="swal2-input" placeholder="Votre Email">',
    preConfirm: () => {
        return {
            name: document.getElementById('name').value,
            email: document.getElementById('email').value
        };
    }
});

5. Personnalisation des paramètres

SweetAlert2 permet de personnaliser l'apparence des alertes, notamment :

  • Position de l'alerte : Définissez où l'alerte doit apparaître sur l'écran.
    • Swal.fire({
    position: 'top-end'
});
  • Durée de l'affichage : Définissez un délai après lequel l'alerte se ferme automatiquement.
    • Swal.fire({
    timer: 5000, // 5 secondes
    timerProgressBar: true
});
